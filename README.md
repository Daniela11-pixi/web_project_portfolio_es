# Portafolio de Daniela Mandujano

Portafolio del sprint 4 de TripleTen: perfil, habilidades, proyectos y contacto. Implementado con HTML y CSS a partir del diseño proporcionado en Figma.

## Ver el sitio

[GitHub Pages](https://daniela11-pixi.github.io/web_project_portfolio_es/)

La dirección requiere subir los cambios y tener Pages configurado para publicar desde la raíz de la rama main.

## Desarrollo

Abre index.html en un navegador o usa Live Server en VS Code. No requiere instalación de dependencias.

La hoja principal es `styles/styles.css`; `styles/fonts.css` conecta las fuentes locales y `styles/normalize.css` normaliza los estilos del navegador.

## Técnicas

- HTML semántico y nombres de clases BEM.
- Flexbox y Grid; puntos de ruptura en 1023 y 767 px.
- Open Sans y Archivo Black locales en formato TTF.
- Luces con radial-gradient y calc, velo con linear-gradient, subrayado con degradado.
- Tarjetas 16:9 y foto móvil al 100% con altura de 280 px y object-fit: cover.
- Navegación por teclado y respeto por movimiento reducido.
